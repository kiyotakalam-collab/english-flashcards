# 英作文マスター

英作文用の独立した学習画面は `writing.html`。既存の単語学習は `index.html` にあります。英作文は専用の `kotoba_writing_v1` に保存し、単語学習の履歴とは分離します。

## 採点の範囲

現在の採点は手動です。送信は答案の保存であり、正誤の判定ではありません。答案は未採点で保存され、参考英文・解説を確認して利用者が評価します。参考英文と一致しない妥当な別解も、手動で正解にできます。参考英文の文字列一致を採点として扱いません。

このリポジトリにはAI採点サーバーも世界史アプリもありません。GitHub Pages上でAPIキーを安全に保持する機能がないため、AI自動採点は未実装です。外部の構造化フィードバックはユーザー提供・未検証の評価として取り込めます。設問と答案を含む添削依頼文を表示できますが、アプリが外部AIへ送信する処理はありません。確信度0.5未満の外部評価は判定保留にします。テンプレート類題はAI生成と区別します。

## データと履歴

- 初期問題は独自作成の短文62問・自由英作文4問（合計66問）。教材や公式過去問の転載ではありません。
- 教材の進捗は問題・解答履歴とは別です。初期値は「構文80」の第1項だけが確認済みです。他の項目の完了は推測しません。
- 不正解・一部正解は答案ごとの累積ミスとして残り、後から正解に修正しても過去のミスは消しません。評価の変更は監査履歴に残ります。
- 自由英作文は4観点を各0〜5点、合計20点で手動評価します。書き直しは元の答案との関連を保持します。
- ブラウザーのローカル保存を使います。端末間の自動同期やサーバーバックアップはありません。必要に応じてJSONバックアップをダウンロードします。

## 調査と構成

既存はHTML/CSS/ES Modulesの静的PWAで、画面はタブ切替、単語の保存キーは `ex_flashcards_pwa_v2`。既存の認証やAIバックエンドはありません。英作文は `writing.html` の6画面をhashで切り替え、独立したversion 1のキー `kotoba_writing_v1` を使います。`writing-core.js` が検証・復習・履歴、`writing-data.js` が独自問題、`writing.js` が画面、`writing.css` が専用UIです。外部フォント・CDNは使いません。ホームの入口とオフライン配信物だけを既存側へ追加しました。

保存はWeb Locksで直列化し、対応しないブラウザでは画面内のキューとrevision確認を使います。破損データを自動初期化しません。訂正は同じ答案のauditに追加し、誤答は答案IDごとに一度だけ数えます。問題の削除は論理削除で、過去の答案スナップショットは残します。

## 使い方

1. 短文か自由英作文で問題数・方式・難易度を選択。入力は問題別に自動保存します。
2. 「採点する」で未採点保存し、手動評価を開きます。判定・得点・根拠・必要な分類を入力します。参考英文と異なるだけで誤答にしないでください。
3. 自由英作文は4観点各5点。「主張を保って書き直す」で元の答案と関連付けて再提出し、「回答と履歴」で改善案との差分を色分けします。
4. 復習は1・3・7・14・30日、誤答後10分。早すぎる正解では段階を進めません。期限到来と未定着は別表示です。
5. おすすめは期限到来→最近のミス→低正答率→重要な未演習→維持確認を優先し、正解直後は同じ構文を自動連続出題しません。候補が尽きると停止します。「無制限」は問題数上限がない意味で、無限生成ではありません。
6. 誤答後は「同じ構文を別の文で確認」で別難度も含む別問題を選べます。「あとで」は同じ構文も現在のセッションから除外します。
7. 「問題・データ管理」で追加・編集・非表示・削除、JSON保存・復元ができます。同一IDの矛盾した答案や採点訂正は取り込みを中止します。

## 残る制限

- 意味・文法・自然さ・論理構成をAIが自動判定する機能はありません。自分で評価するか、添削者の外部評価を確認して取り込みます。API未実装のためAPI障害の実通信テストは対象外です。壊れた外部評価JSONでも保存済み答案は保持します。
- 動的テンプレート生成は目的格の関係代名詞の4文脈のみ。他項目は初期の別文脈ペアとユーザー登録問題を使います。全項目の無制限AI生成は未実装です。
- 習熟度・傾向は難易度・記録数・新しさを使う学習上の目安です。合否や将来得点を予測する校正済みモデルではなく、データ不足も表示します。
- 教材との公式対応表は未収録。確認した対応は問題の「出典詳細・教材との対応」に登録できます。教材本文や過去問は無断収録しません。教材進捗を変更するのは明示的な手動入力だけです。
- 認証・サーバー同期はなく、端末・ブラウザーごとの保存です。既存Sheetsは単語専用のままです。JSONを端末外にも保管してください。
