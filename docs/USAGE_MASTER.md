# 語法マスター

## 開き方

- アプリホーム `portal.html` →「語法を学習する」
- 英作文マスターのサイドバー →「語法マスター」
- 英単語画面の入口 →「語法マスター」
- 直接URL：`https://kiyotakalam-collab.github.io/english-flashcards/usage.html`

GitHub Pagesのサブパス上で動くHTML・CSS・ES modules製の独立した画面です。初期20語法は依頼で指定された日本語・英語・例文・カテゴリーを収録しています。API・APIキーは不要です。

## テストと今回の誤答復習

出題数10・20・30・全問、カテゴリーを指定し、ランダムに重複なく出題します。登録数より多く指定した場合は、出題可能な問題を全問使い、実際の問題数を表示します。まず日本語だけを表示し、記述回答後に正誤・正答・例文を開きます。Enterで回答、結果の後はEnterで次へ進めます。

1つのテストに問題文のスナップショットと誤答IDを保存します。テスト終了後の「今回の誤答だけを復習」は、そのテストの未解決の誤答だけが対象です。不正解は次の周回にも残り、正解した語法は除外されます。全問解決すると復習完了です。新しいテストを始めた後は、新しいテストの誤答だけを復習します。

回答はテスト・誤答復習ごとに日時付きで独立保存します。累積誤答は履歴から集計し、正解しても減らしません。二重送信はセッションID・問題位置・回答フェーズで防ぎます。入力・問題位置・結果表示・復習の残りを保存し、画面更新後も途中から再開します。

## 判定と重複防止

許容する差：大文字小文字、Unicodeの半角／全角、前後や連続した空白、文末のピリオド、宣言した変数の表記です。

- `be distracted by A` と `BE DISTRACTED BY ～.` は正答かつ重複扱い。
- 変数 `A`、`B`、`C`、`～`、`人`、`もの`、`someone`、`something` 等をプレースホルダーとして扱います。
- 登録時は変数を大文字の `A` 等、冠詞を小文字の `a` で記述します。`S V` は主語・動詞の型としてそのまま入力します。
- `be available to A` と `be available for A` は異なる語法です。
- 前置詞・語順・動詞形・冠詞の省略は許容しません。

これは登録された形を再現するための自動判定です。AIによる意味判定や、未登録の言い換え全般を正解にする機能ではありません。重複チェックも、意味の似たすべての表現を推測統合せず、上記の表記差を対象にします。

## 今後の語法を追加する

「語法の管理」で日本語・覚える英語・短い例文・カテゴリーを入力し、「語法を保存」を押します。カテゴリーは動詞語法・形容詞語法・名詞語法・定型表現・前置詞・その他です。非表示の項目も重複チェックに含めます。編集で固定IDと作成日時は変えず、更新日時だけを更新します。「出題対象にする」を外すと次のテストから除外され、履歴は残ります。進行中のテストは開始時のスナップショットで続行します。

初期教材は `usage-data.js`。今後の追加は管理画面が基本です。初期ファイルを編集するだけでは既存端末の語法マスターを上書きしません。管理画面での追加内容はその端末に保存され、Google Sheetsや他の端末へ自動共有しません。

## データとオフライン

保存キーは `kotoba_usage_v1`（schemaVersion 1）。語法、テスト、回答、途中の入力・復習、設定を保存します。英単語の `ex_flashcards_pwa_v2`、英作文の `kotoba_writing_v1` など、別アプリのキーは読み書きしません。JSONの書き出し・取り込みも語法専用です。

取り込みはIDで統合し、同じ回答を二重に数えません。同じテストの新しい履歴が片方にのみある場合はその進行状況を保持し、両方で異なる履歴に分岐している場合は取り込みを中止します。不正な保存データを自動初期化しません。容量不足で保存できないときも、既存の保存内容を消さずにエラーを表示します。

ビルドとService Workerのキャッシュ対象に専用画面・データ・コードを含め、オンラインでオフライン準備完了後は通信なしで起動・採点・復習・管理できます。既存画面に新しい入口が見えない場合は「最新版に更新」を使うか、`refresh.html` から履歴を保って画面を更新してください。

## 検証

- `node --test tests/usage.test.js`：指定20語法、表記正規化、厳密な語法判定、重複、出題数・カテゴリー、今回の誤答の分離、複数周回、累積誤答、二重送信、保存・復元・容量不足。
- `npx playwright test tests/browser/usage.spec.js`：入口、記述式・キーボード、誤答復習完了、管理、360px・393px、他アプリの保存領域へのアクセス監査、途中再開、実Service Workerによるオフライン再起動と旧PWA更新、複数タブの問題・採点対象の一致、JSON取り込み、保存失敗。
- `npm test`：英単語・英作文・聞き流し・復習など既存の回帰テストを含む全体確認。

このリポジトリには世界史誤答マスター・年号マスターのコードは含まれていません。それらのコードや保存キーは変更しておらず、関連する模擬保存キーもスマホテストで読み書きしないことを確認します。
